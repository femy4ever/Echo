## Third-party assets

None. ECHO doesn't use any outside images, sounds, fonts, libraries, or frameworks.

- **Graphics** are drawn live with the HTML5 Canvas 2D API.
- **Sound** is synthesised live with the Web Audio API. There are no audio files.
- **Text** uses whichever monospace font the player's device already has.

## Techniques

These are well-known, freely used methods, written from scratch here:

- *Recursive backtracker*, a classic maze generation method.
- *Breadth-first search (BFS)* for path finding.
- *DDA grid traversal* for ray casting.
- *mulberry32*, a public-domain seeded random number generator.
